# Reversão visual do nav — 18/08/2026

A moldura contínua aplicada ao cluster `Escala atual / Competência / Status` foi removida. O Dashboard voltou a apresentar os três controles separados no topbar, sem uma caixa atravessando o nav e sem divisórias internas pesadas.

A tela Escalas permaneceu funcional e visualmente estável após a reversão. Os controles interativos continuam com suas bordas individuais e o cluster mantém o comportamento original de seleção de contexto e competência.
